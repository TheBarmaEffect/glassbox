Extension privacy

Effective August 11, 2026.

GlassBox Lite audits only text that you explicitly paste into the extension or explicitly select before choosing the GlassBox context-menu action. A context-menu selection is held temporarily in browser session memory, consumed once when the audit page opens, and removed before any audit runs.

The extension does not inject a content script, monitor pages, read browsing history, collect telemetry, create an account, use cookies, or store submitted questions, answers, requirements, or audit results. It has no API key or embedded secret.

Nothing is sent until you press Run audit. At that point, the displayed question, answer, and optional requirements are sent over HTTPS to https://glassbox-platform-gateway.onrender.com/mcp. The gateway runs the deterministic GlassBox Lite verifier and returns a privacy-minimized result. Render hosts the gateway.

The extension displays verifier strings only as inert text. It does not render returned HTML, create returned links, execute returned instructions, or browse the web. Results are reasoning-audit signals, not fact-checks or professional advice.

See the service privacy notice for gateway retention and contact details. Support and privacy requests: thebarmaeffect@gmail.com.
