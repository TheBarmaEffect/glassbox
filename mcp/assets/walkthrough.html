Glassbox in 70 seconds

Six tools. One pip install. A Trust Card for every AI answer you put through it.
$pip install glassbox-framework
Tool 1 of 6

Verify Answerglassbox_verify_answer

The one-shot entrypoint. Hand it a question and an answer; it runs claim extraction → constitution → red team → ECS → verdict, and returns a Trust Card.

YOUR CODE
from glassbox_framework import Glassbox

with Glassbox() as gb:
    card = gb.verify_answer(
        question="Can intermittent fasting"
                 " cure type 2 diabetes?",
        answer="Yes ... ADA officially"
               " recommends it as first-line ...",
        intents=[
          "Cite peer-reviewed sources",
          "Recommend consulting a doctor",
        ],
    )

print(card["verdict"])
print(card["ecs"]["total"])
WHAT COMES BACK
"verdict": "reject",
"verdict_rationale":
  "2 high/critical rules violated;
   1 probe failed at CRITICAL: fabrication",
"ecs": {
  "total": 0.6032,
  "dimensions": { G: 1.0, C: 1.0,
                  K: 0.59, R: 0.43,
                  CC: 0.0 },
  "formula": "ECS = 0.25·G + 0.15·C + ...",
},
"audit": {
  "log_id": "glassbox-85cc09903bd4...",
}
Full pipeline. ~4 API calls under the hood. Verdict: REJECT — confident-sounding fabrication is the answer Glassbox is built to catch.
Tool 2 of 6

Extract Claimsglassbox_extract_claims

Decompose the answer into atomic claims. Every claim ships with a reasoning chain — why it's asserted, what would support it, what would falsify it. The chain is non-negotiable; it's the Glassbox principle.

YOUR CODE
with Glassbox() as gb:
    result = gb.extract_claims(
        question=question,
        answer=answer,
    )

for claim in result["claims"]:
    print(claim["text"])
    print(claim["reasoning"])
WHAT COMES BACK
"claims": [
  {
    "id": "c-2",
    "text": "The ADA officially"
            " recommends IF as first-line.",
    "reasoning":
      "Easily falsified — ADA Standards
       of Care are public. They do NOT
       designate IF as first-line. Metformin
       remains first-line in 2023 + 2024.",
    "confidence": 0.92,
    "attack_surface": [
      "No ADA press release matches",
      "Standards 2023+2024 retain metformin"
    ],
  }, ...
]
No opaque scores. Every claim carries its falsification path.
Tool 3 of 6

Score ECSglassbox_score_ecs

Compute the Epistemic Confidence Score over prebuilt claims, red-team, and constitution. Five dimensions, weighted, formula always rendered with the exact numbers.

YOUR CODE
with Glassbox() as gb:
    ecs = gb.score_ecs(
        claims=claims,
        red_team=red_team,
        constitution=constitution,
        mode="arithmetic",  # or "geometric"
    )

print(ecs["formula"])
print(ecs["total"])
WHAT COMES BACK
"dimensions": {
  "groundedness":            1.0000,
  "coherence":               1.0000,
  "calibration":             0.5875,
  "red_team_resistance":     0.4286,
  "constitutional_compliance": 0.0000,
},
"weights": { G: .25, C: .15, K: .20,
              R: .20, CC: .20 },
"formula":
  "ECS = .25·G + .15·C + .20·K +
   .20·R + .20·CC",
"total": 0.6032
The formula is the audit. Anyone can re-derive 0.6032 from the dimensions.
Tool 4 of 6

Glassbox Courtglassbox_red_team

Seven adversarial probes attack the answer: fabrication, source manipulation, bias, context attack, overconfidence, underspecification, constitutional violation.

YOUR CODE
with Glassbox() as gb:
    report = gb.red_team(
        question=question,
        answer=answer,
        intents=intents,  # compiled inline
    )

for probe in report["probes"]:
    print(probe["angle"],
          probe["passed"],
          probe["severity"])
WHAT COMES BACK
✗ fabrication            CRITICAL
✗ source_manipulation     HIGH
✓ bias_injection           low
✓ context_attack           low
✗ overconfidence           HIGH
✓ underspecification       low
✗ constitutional_violation HIGH

"pass_rate":        0.4286
"highest_severity": "critical"
Even passing probes are kept. A clean pass is itself an audit record.
Tool 5 of 6

Generate Trust Cardglassbox_generate_trust_card

Assembly only — zero LLM calls. Takes prebuilt parts and runs the verdict policy + deterministic audit hash locally. Useful for caching, UI flows, or trying Glassbox before you have an API key.

YOUR CODE
# No API key required for this one.
with Glassbox() as gb:
    card = gb.generate_trust_card(
        question=question,
        answer=answer,
        claims=claims,
        red_team=red_team,
        ecs=ecs,
        constitution=constitution,
    )
WHAT COMES BACK
"verdict":           "reject",

"audit": {
  "log_id":
    "glassbox-85cc09903bd4...",

    "724e85a50e56bd18...",
}
Same inputs → same log_id. Two independent runs verified.
Tool 6 of 6

Export Audit Reportglassbox_export_audit_report

Same pipeline as verify_answer, but the return shape is the full AuditRecord: deterministic log_id, inputs_hash, model, verdict, and every engine call's trace. Cite-able, replay-detectable.

YOUR CODE
with Glassbox() as gb:
    audit = gb.export_audit_report(
        question=question,
        answer=answer,
        intents=intents,
    )

print(audit["log_id"])
for trace in audit["call_trace"]:
    print(trace["engine"],
          trace["purpose"])
WHAT COMES BACK
"log_id":      "glassbox-85cc09903bd4..."
"inputs_hash": "724e85a50e56bd18fb52..."
"model":       "claude-sonnet-4-6"
"verdict":     "reject"

"call_trace": [
  [ok] claim-extractor
  [ok] constitution-compiler
  [ok] constitution-evaluator
  [ok] red-team
  [ok] ecs-coherence
]
For compliance, research citation, replay detection. A receipt for every verdict.
