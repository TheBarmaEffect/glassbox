GlassBox Platform Privacy Notice

Effective August 10, 2026.

GlassBox performs a user-requested automated reasoning audit. It processes the question, answer, and optional rules that a user explicitly submits or selects. The gateway also handles provider event IDs and short-lived requester identifiers—such as Discord user/server IDs, Slack user/workspace IDs, Telegram user/chat IDs, GitHub sender/repository IDs, and Reddit author/subreddit IDs—for authentication, duplicate prevention, delivery, abuse prevention, and rate limiting.

Processing and sharing

The default GlassBox Lite verifier processes submitted text deterministically inside the gateway process. It does not call a paid model API or browse the web. The gateway does not pass platform user IDs, workspace/server/community names, repository names, URLs, or author metadata to the verifier. If the operator later enables an optional third-party verifier, that change and its applicable processing terms must be disclosed to users before use.

Retention

This gateway does not persist raw questions, answers, platform messages, or Trust Cards to a database or file. Submitted content and its Trust Card exist in process memory while an audit runs and, after verification, for at most five minutes while platform delivery is confirmed. It keeps provider event identifiers in memory for up to 24 hours to prevent duplicate processing and requester/tenant identifiers in memory for up to 10 minutes for rate limiting. Process memory is discarded on restart. Telegram requires explicit per-audit consent before text is sent. Platform providers may retain messages under their own policies.

Logs and security

Operational logs record service status and error categories, not submitted content. Provider signatures protect webhook endpoints, and the generic API requires a server-side bearer secret.

Your choices

Analysis is opt-in. Telegram consent applies to one audit and is not stored; Slack public delivery occurs only when --public is the first command argument. Do not submit confidential, regulated, or third-party content unless you have authority to do so. Because the gateway does not retain submitted content, there is normally no stored content to access, transfer, correct, or delete. You can delete the bot's visible response using the controls offered by the platform. For a data-rights request or to revoke platform authorization, email the contact below and identify the relevant platform and app installation; do not email the confidential content itself.
