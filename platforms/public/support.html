glassbox

Install and support

GlassBox Lite is a generally available, free service that audits an explicitly selected AI answer and returns a deterministic Trust Card. It charges no fee, accepts no payment, needs no paid model API, and does not persist the raw question or answer. Render hosts the gateway infrastructure.

Discord

Install GlassBox, then run /glassbox or use the Analyze with GlassBox message action.

Telegram

Open @GlassBoxAuditBot and follow the bot prompt to audit an answer.

GitHub

Install GlassBox by Aura on only the repositories you choose. On an issue or pull request, comment /glassbox question || answer. The app reads repository metadata and can write issue comments so it can return the Trust Card.

ChatGPT, Claude, and other MCP clients

Add a custom remote connector using https://glassbox-platform-gateway.onrender.com/mcp. The endpoint is public and auth-free. Its privacy-minimized result does not echo submitted text or expose internal audit metadata. The ChatGPT and Claude directory listings are still subject to each platform's external review and account requirements.

Other platforms

Slack is live in the initial workspace while Marketplace distribution is prepared. Reddit is awaiting Devvit Fetch-domain and public-directory approval. These are not represented as public-directory listings until the platform approves them.

Troubleshooting

If a command does not appear immediately, restart the client or allow a few minutes for global command propagation. For product help or privacy requests, email thebarmaeffect@gmail.com. Identify the platform and, if that platform shows one, the audit reference; never email sensitive question or answer content.

Security and incident response

Report suspected vulnerabilities or security incidents to thebarmaeffect@gmail.com. Include the affected platform, approximate time, and safe reproduction details, but never send credentials, tokens, or sensitive submitted content. Karthik Barma, the individual operator, will triage the report and take reasonable containment and remediation steps. If an incident is confirmed to affect the GitHub Marketplace integration or GitHub data, the operator will notify GitHub within 24 hours of confirmation whenever GitHub Marketplace requirements require that notification, and will notify affected users or platform owners when applicable.
